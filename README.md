# Daily News Hub

A clean, real-time news aggregator built with pure HTML/CSS/JS.

Live site: **https://ansonlo1560.github.io/daily-news-hub/**

## News Sources

| Category | Sources |
|----------|---------|
| Hong Kong | RTHK, SCMP, HK01 |
| China | Xinhua, China Daily, Global Times |
| World | BBC, Reuters, AP |
| Tech | TechCrunch, The Verge, Ars Technica |
| Finance | FT, Bloomberg, WSJ |
| Sport | BBC Sport, ESPN |

## Features

- Live scrolling ticker with latest headlines
- Filter by category tabs
- Auto-refreshes every 15 minutes
- HKT clock display
- Dark modern UI with animations
- No build tools — pure single HTML file

## Deploy

Hosted via [GitHub Pages](https://pages.github.com/). No server required.
